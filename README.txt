BELLA MASSA PIZZERIA — NOVA VERSÃO

ARQUIVOS
- index.html: estrutura e conteúdo do site
- style.css: visual e adaptação para computador/celular
- script.js: cardápio, filtros, montagem de pizza, carrinho e cadastro do Clube

COMO TESTAR
1. Extraia bella-massa-site.zip.
2. Abra index.html no navegador.
3. Teste a busca e os filtros do cardápio. O cardápio agora inclui 20 sabores de pizza em três categorias.
4. Adicione pizzas, altere quantidades e remova itens no carrinho.
5. Monte uma pizza personalizada e confira o valor calculado.
6. Atualize a página: o carrinho deve continuar salvo no mesmo navegador.

PUBLICAR NO GITHUB / VERCEL
Envie index.html, style.css e script.js para a pasta principal do projeto. Se houver arquivos antigos com esses mesmos nomes, substitua-os. Aguarde o novo deploy da Vercel e atualize a página com Ctrl+F5.

IMPORTANTE SOBRE ESTA VERSÃO
Este é um site estático, sem servidor ou banco de dados. O carrinho e o cadastro do Clube são salvos apenas no navegador usado. O botão de finalizar pedido baixa um resumo .txt para conferência; não processa pagamentos, não envia o pedido para a pizzaria e não calcula frete real. Para receber pedidos de verdade, será necessário integrar um número oficial de WhatsApp, backend/banco de dados e, se desejado, um provedor de pagamento. Os preços e itens exibidos são exemplos editáveis e devem ser confirmados pela pizzaria antes de publicar.


CARDÁPIO AMPLIADO
O cardápio inclui pizzas salgadas, 6 pizzas doces e 8 bebidas. Preços e disponibilidade são exemplos e devem ser confirmados pela pizzaria antes de publicar. Alguns itens usam imagens ilustrativas.
